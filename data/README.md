## 一之二、M0 数据底座复核（2026-10-15 实测，接口参数勘误）

**历史日期查询可用**（这是"多期快照"模块的可行性前提）：

- 请求参数为 **`pubDateStartTime` / `pubDateEndTime`**（形如 `2026-08-06`），**不是** `startDate`/`endDate`。
  实测 `startDate`/`endDate` 被接口忽略、返回最新一期数据（日期仍为 2026-10-14）——**若按此实现会静默拿到同一期数据，两期快照退化成同一期**。
- 实测三日期取回的大白菜均价与题面一致：2026-08-06 = 0.55 / 2026-09-06 = 0.53 / 2026-10-06 = 0.40（元/斤）。

**品类 id 实测**（`prodPcatid` 参数）：

| id | 品类 | 单日记录数（2026-10-14 实测） |
|---|---|---|
| 1186 | 蔬菜（含水菜） | 132 |
| 1187 | 水果（梨/柑橘/桃李杏/西瓜/香蕉/甜瓜/苹果/葡萄/芒果） | 86 |
| 1189 | 肉禽蛋（猪肉/牛肉/羊肉/禽蛋） | 141 |
| 1190 | 水产（淡水鱼/海水鱼/虾蟹/贝壳） | 113 |

（1188 / 1191 / 1192 实测返回 0 条，不采用。）

**`prodName` 过滤勘误**：题面注记"prodName 过滤无效需用 prodPcatid"**只在单独使用 prodName 时成立**——实测 `prodName` + `prodPcatid` **组合**过滤有效（返回指定品名的多日记录）。M0 据此修正题面表述。

**抓取纪律**：快照入库须记录抓取日期、URL、原始响应文件名 + sha256；快照文件只增不改（`.gitattributes` 已标 `data/snapshots/** -text` 防 EOL 改写字节），两期对比用不同文件。

## 三、合成数据纪律

- 演示/样例数据一律合成，禁止使用真实门店/真实经营者信息。
- **假店名白名单**（样例进货单/演示数据专用）：`示例食堂甲`、`示例小馆乙`、`示例快餐丙`。白名单外新增须先在此登记。
- **真实价格数据**：仅使用新发地公开批发价快照，逐份记录抓取日期；真值表中的价格字段必须可追溯到快照文件。
- 合成真值由确定性引擎程序化生成并植入期望输出，禁止手写期望值。
- 覆盖度口径：各基准套件按模块（导入/换算/定价/预警）列最低覆盖项，写入 plan/03 与 plan/00 台账，防真值偏科。

## 四、口径纪律

数值口径（净料单价公式、毛利率反推公式、四舍五入规则、波动预警阈值默认值）**只在一处定义**（plan/02 算法与口径说明 + `src/rcc/rules/formulas.py`），本文件与题面注记均为引用，不得手写第二份口径。默认值（损耗率、预警阈值等）均为经验示例值，注明非官方出处。
