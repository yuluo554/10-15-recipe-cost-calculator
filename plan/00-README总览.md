## 五、纪律

- 不写会随实现漂移的硬数字（测试数/用例数/体积/通过数），指标只写口径与门槛来源；确需数字"以末态回填"。
- 数值口径一处定义（引擎参数/公式定义处），注记与文档多处引用，禁止手写第二份口径。
- 每个"未挂来源"的参数不得进入计算路径。
