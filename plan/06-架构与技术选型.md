# plan/06 架构与技术选型

仓库 `10-15-recipe-cost-calculator`。v1（2026-10-15）。M0 定稿。

## 一、技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 语言 | Python 3.8+（本机通道 3.8.8 / 3.12.10） | 底线 3.8；CI 矩阵 windows×{3.8,3.12} + ubuntu×{3.12} |
| 核心依赖 | **零第三方**（纯 stdlib） | 引擎/解析/基准零依赖 → 结论 100% 可复现、基准离线可跑、脱敏面无外部调用 |
| 金额类型 | `decimal.Decimal` 全链路（`parse_float=Decimal`） | F4/F5 要检出 1 分差异，float 尾差不可接受 |
| 确定性 RNG | 自研 splitmix64（`tools/detrng.py`） | stdlib `random` 不承诺跨版本序列一致 |
| 报告 writer | 自写最小 OOXML writer | 第三方库的 ZIP 元数据（宿主系统标识/时间戳）会让字节漂移，破坏"同输入同字节"承诺 |
| GUI | PySide6（可选 extra） | 系列标准形态；GUI 只消费编排层 API |
| 打包 | PyInstaller **≥6**（onedir 双 exe） | 打 GUI 必须 ≥6（5.x 确定性崩）；发布构建固定用装了 ≥6 的通道（`py -3.12`） |
| LLM | **不使用** | 本领域是纯确定性规则 + 结构化输入，无"非结构化解析兜底"需求 → 全链路零 LLM（决策记录已登记） |

## 三、分层与单向依赖

```
cli.py ──┐
gui/   ──┴─→ engine/pipeline.py（编排层，唯一业务判断入口）
                │
                ├─→ rules/（formulas + params 门控）
                ├─→ io/（解析）
                ├─→ alert/
                └─→ report/
```

**硬纪律**：
- **编排上收**：CLI 与 GUI 共用 `engine/pipeline.py` 的公开函数组，前端只渲染、零判定逻辑——**同一业务判断在项目里只能有一处实现**；
- **GUI 分层靠 AST 静态门禁守住**（三条齐上）：① 不 import 规则层/引擎内部模块；② 无 `BinOp` 算术（`*` `/` `-` `//` `%` `**`，两侧操作数均非字符串字面量）；③ 无禁用数值字面量。**只守 import 面会漏掉"界面里直接算/内联数值"**；
- **惰性导入**：重件（PySide6）只在函数体内 import；`try/except ImportError` 必须包住**从 import 到调用完成的整条路径**（不是只包 import 行——分层越严，这个边界越靠后越易漏）；
- **单件与批量共用同一分派点**（`check` 与 `batch` 走同一个解析/判定函数，别复制粘贴判定逻辑）。

## 四、口径单一定义点（防"第二份真相"）

| 事实 | 唯一定义点 | 引用方 |
|---|---|---|
| 换算公式 F1–F6 | `rules/formulas.py` | 引擎 / 报告 / 基准 / plan/02 |
| 参数默认值与 status | `data/rules/params-*.json`（生成器产出） | 引擎（经 `effective_params` 门控）/ 报告参数来源块 |
| 报告章节结构 | `report/sections.py` | Markdown 渲染器 + XLSX 渲染器（→ 内容一致是结构性质） |
| 真值对账语义 | `benchmark/cases.py` | 真值库测试 + 基准（→ 无双口径漂移） |
| 打包数据白名单 | `rcc/packaging.py` | spec / 构建后断言 / 白名单守门测试 |

**零字面量门禁**（`tools/check_literals.py`）扫描面随交付形态扩张：`engine/` `alert/` `rules/` `cli.py` `report/` `gui/` `benchmark/`，含 docstring 与注释。新增源码文件前先问：**"这个文件里会出现任何禁用数值形态的字符串吗？"**

## 五、数据流（端到端）

```
进货单 CSV/XLSX ──解析──┐
                        ├─→ 食材库（品名→类别/单位/参考价/净料率参数）
新发地快照 JSON ────────┘         │
                                  ↓
菜品 BOM ──────────→ 成本卡引擎（F1 净料换算 → F2 BOM 汇总）──→ 成本卡
                                  │
参数包（净料率/毛利率）──────────┤
                                  ↓
                        毛利率定价（F3 反推售价 / F4 实际毛利率）
                                  │
两期快照 ──→ 波动预警（F5 涨跌幅 + 阈值 → 受影响菜品清单）
                                  │
                                  ↓
                        报告（人读 MD + 机读 XLSX，单一渲染源）
```

## 七、边界与非目标（复核题面 §6）

- **不做**：进销存系统、财务系统（总账/报表/税务）、点餐收银系统；
- **不联网拉价**：首期只用内置快照（含抓取日期）；联网拉取列扩展项；
- **免责红线**：辅助核算工具，非财务/经营决策工具；损耗率/毛利率默认值为**经验值（非官方出处）**；
- **隐私红线**：纯本地运行，无账号、无上传、无遥测；演示数据一律合成假数据（假店名白名单见 data/README.md）；
- **品牌隔离**：与系列其他项目代码零复制、文档互不提及对方业务领域（提及姊妹项目一律用**方向级描述**，不落具体领域名词）。
