# 10-15-recipe-cost-calculator：菜谱/食堂采购成本核算器

> **性质**：模拟项目题（不参赛项目题，发布 GitHub 公开仓库，署名 yuluo554）
> **目标产出**：仓库 `10-15-recipe-cost-calculator`；交付形态 = PySide6 桌面 exe + CLI 双形态（系列标准形态），纯本地运行
> **版本史**：v1（2026-10-14）初版定稿
> **命名约定**：日期标签目录 `10-15-` 前缀，纯净名 `recipe-cost-calculator`

> **定位宣言**：小餐饮的成本卡都在老板脑子里和 Excel 里——本工具把"进货单导入 → 净料换算 → 菜品成本卡 → 毛利率定价 → 价格波动预警"做成**确定性规则引擎**，内置公开批发价数据快照做基准真值，可复现可评测。Excel 和聊天都给不了：Excel 不会自动净料换算、不会在两期价格快照间自动重算受影响菜品并出预警清单；LLM 聊天给不了持久库、确定口径与可复现基准。

## 一、介绍

**痛点与证据**：小餐饮店/食堂的采购成本核算普遍停留在"老板记忆 + Excel 手工表"：进货价每天变、毛料换净料凭经验、一道菜到底挣多少钱没人算得清。UGC 直接取证（知乎等）⬜ 未直连获取（403 阻断，见 data/README.md），本题面以**实测价格波动数据替代论证**：新发地批发价格 API 实测（基准日 2026-10-14），大白菜 avgPrice 2026-08-06=0.55 元/斤 → 2026-09-06=0.53 元/斤 → 2026-10-06=0.40 元/斤（两月 -27%）。同类菜品两个月内成本波动可达两成以上，手工 Excel 既不会感知、更不会重算——这正是"波动预警"模块的需求实证。

**方法论锚点（降级表述，⬜）**：传闻中的《餐饮业成本核算规范》SB/T 10573 **未查证到**（国内贸易行业标准库 hbba.sacinfo.org.cn 以"餐饮"检索 43 条，无成本核算类标准，实测 2026-10-14）。现存 SB/T 11166-2022《餐饮服务单位节约管理规范》等为管理规范，非核算方法标准。本题面方法论锚点因此**只锚定"行业惯例 + 烹饪教材方法（毛料→净料出成率换算）"，⬜ 待核对（入库时以烹饪教材原文核对），不引用任何编造的标准号**。

**开源空白**（软论据 ⬜，检索式与基准日可回溯）：GitHub 检索 "recipe cost calculator" 147 结果，最高 3★ 且均为个人食谱向、无进货单导入；"食堂+成本+核算" 0 结果；中文最接近项目 zhuatech-recipeflow 为商用需授权、非纯开源。基准日 2026-10-14。

## 二、任务要求

首期范围限定为 **4-5 个模块**（M1-M5 对应，见 plan/00 里程碑），其余列扩展项。每模块含输入/输出/确定性纪律。

### 模块① 食材库与进货单导入
- **输入**：CSV/Excel 进货单文件（列：日期、品名、类别、数量、单位、单价、金额）；新发地公开数据快照样例文件（真实抓取记录，含抓取日期）。
- **输出**：本地食材库（品名→类别/单位/参考价/净料率参数）；进货记录台账。
- **确定性纪律**：解析规则确定（列名白名单 + 类型校验，异常行列出清单不静默跳过）；入库参数须挂来源标记（快照日期/用户自填），未挂来源不得进入计算路径。

### 模块② 成本卡引擎（净料换算 + BOM 汇总）
- **输入**：菜品配方 BOM（食材→用量）；每食材的净料率/损耗率参数（**用户可配置 + 内置经验默认值，注明非官方出处**，⬜ 无权威公开官方表，见 data/README.md）。
- **输出**：菜品成本卡（毛料单价→净料单价→BOM 汇总→单份成本），换算过程逐行可追溯。
- **确定性纪律**：换算公式确定：`净料单价 = 进货单价 ÷ 净料率`（同一公式一处定义，引擎、注记、文档多处引用同一口径）；损耗率取值须有参数来源标记，默认值不得冒充官方数据。

### 模块③ 毛利率定价
- **输入**：菜品成本卡；目标毛利率（用户配置）。
- **输出**：目标毛利→建议售价反推（`建议售价 = 成本 ÷ (1 - 目标毛利率)`）；按实际售价核算实际毛利率。
- **确定性纪律**：公式确定、四舍五入规则显式声明（一处定义）；目标毛利率为用户参数，工具不做"定价建议"类模糊输出。

### 模块④ 价格波动预警
- **输入**：两期价格快照（内置新发地公开快照或用户导入，快照须含抓取/导入日期）。
- **输出**：受影响菜品清单（BOM 含该食材者）逐菜重算前后成本差；预警清单（超过波动阈值的食材/菜品，**阈值为用户可配置参数**，默认值标注非官方）。
- **确定性纪律**：重算与排序规则确定（按涨跌幅降序）；预警 ≠ 判定，仅输出提示清单，不自动改价。

### 模块⑤ 内置基准
- **输入**：以新发地真实价格快照为真值的核算样例集（含进货单样例 + 期望成本卡/预警输出）。
- **输出**：基准真值表 + 复跑脚本（可程序化复验）。
- **确定性纪律**：真值由确定性引擎生成并留档；样例数据可程序化生成带真值植入；覆盖度口径（按模块列最低覆盖项）写入 plan/00 台账，防真值偏科。

### 扩展项（首期不做）
- 营养成分辅助：以食品伙伴网食物营养数据库（db.foodmate.net/yingyang/，✅已获取，1500 余种食物 24 项指标，免费直连）为辅助源，做菜品营养概算。非首期承诺。
- 多门店：门店间独立库与台账对比。非首期承诺。
- 联网拉价：见边界与非目标。

## 六、边界与非目标

- **不做**：进销存系统（不管理出入库流水）、财务系统（不做总账/报表/税务）、点餐/收银系统。
- **不联网拉价**：首期只用内置价格快照（含抓取日期留档）；联网拉取列为扩展项，首期不承诺。
- **免责红线**：本工具为辅助核算工具，非财务/经营决策工具；损耗率/毛利率等参数默认值为经验值（非官方出处），用户须自行核对。
- **隐私红线**：纯本地运行，无账号、无上传、无遥测；演示/样例数据一律使用合成假数据（**假店名白名单**见 data/README.md），真实价格仅使用公开批发价快照并记录抓取日期。
- **品牌隔离**：与系列其他项目代码零复制、文档互不提及对方业务领域。
- **首期范围限定**：模块①-⑤，扩展项（营养成分辅助、多门店、联网拉价）不进首期 DoD。
